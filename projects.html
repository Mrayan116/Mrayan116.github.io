InboxIQ

AI Assistant

InboxIQ is an AI-powered email assistant designed to help users manage large amounts of email more efficiently. It analyzes messages and organizes them based on their urgency and importance, making it easier to identify what needs attention first.

The tool can also generate smart email replies, create quick notes, and summarize long emails. The goal is to reduce the time users spend sorting through their inbox while still helping them understand and respond to important messages.

CodeColleague

AI Coding Tutor

CodeColleague is an AI-powered programming assistant built to help users learn, practice, and solve coding problems. Instead of only reviewing code, it acts more like a programming tutor that can guide users through different challenges.

Users can bring coding problems, ask questions, debug their programs, understand unfamiliar code, and receive hints when they are stuck. It also includes different practice activities, from quizzes to smaller coding problems and larger challenges.

03

Sustainability Recycling Game

3rd Place • MillHacks

For the MillHacks hackathon, my team built a sustainability focused game using Python. The goal was to create the best game while following the competition's requirement to use Python.

In the game, different types of waste fall from the top of the screen and the player must sort each item into the correct bin. Players have to quickly switch between recycling, garbage, and organic bins while trying to correctly sort as much waste as possible.
